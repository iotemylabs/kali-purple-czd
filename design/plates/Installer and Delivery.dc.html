This one covers how it gets onto a disk and how it gets to people: the installer's first screen, the partition screen where a wrong click costs someone their thesis, the progress slideshow, and the sheet that says what is published and how to check it. Calamares is where respins leak hardest — stock Breeze sidebar, a default slideshow selling Debian, a download page with no checksum.
THE RULE FOR THIS BATCH · Gold stays the only accent, including on the destructive screen — there is no red panic state anywhere in CZD, so the partition screen earns its weight from 2px rules, the warm well surface and copy that names the consequence. The two grey status hues appear once, on the USB you booted from, to say do not install onto this. Everything drawn here consumes czd-purple-tokens.json.

01 · THE SIDEBAR IS THE SCHEDULE ROW
Calamares ships a Breeze list with icons and a progress dot. CZD replaces it with the pattern every other surface already uses — a zero-padded gold numeral beside an uppercase mono label, current step on the 0.05 tint with a 1px gold border. Same construction as a selected nav item on the site.
02 · SEVEN STEPS, NOT NINE
Stock Calamares shows locale and keyboard as their own pages and then asks again in a summary. Locale and keyboard collapse onto the welcome screen because both are already known from the live boot, which removes two clicks and leaves partitions as the only screen that needs thought.
03 · SAY THE SECURE BOOT THING HERE
An unsigned image that fails to boot after a 20-minute install is the worst bug report CZD can generate. The warm well surface with 2px gold caps carries it on the first screen, in the same voice the LUKS prompt uses: the fact, the fix, and what it costs you if you skip it.
04 · ONE FILLED GOLD THING
NEXT is the only fill on the screen and it is the loudest element in the system, so there is exactly one per step. BACK is a disabled mono label at #6B6152 — no ghost outline, no opacity trick — and QUIT keeps its arrow attached to the label, pointing back the way you came.

01 · NO RED, SO SPEND WEIGHT INSTEAD
The destructive screen gets its severity from structure: the disk table sits between 2px gold rules, and the consequence block is the only #181307 warm well on the plate, capped top and bottom. A red banner would be louder and less legible; a plane change and a hard rule read from across a room.
02 · THE BOOT STICK IS GREYED, NOT HIDDEN
Hiding sda would be a lie about what is plugged in. It stays listed, unselectable, marked IN USE in the one non-gold hue the system keeps for "nothing live here" — the only place in the whole respin where a status hue does real work.
03 · ENCRYPTED BY DEFAULT
A laptop full of capture files and client notes leaves the building at 5 PM. Erase-and-encrypt is selected on arrival and the passphrase field is focused; manual stays one click away for people who partition for a living. /boot stays outside the container so GRUB can theme itself.
04 · THE MAP IS TO SCALE-ISH
EFI and /boot are drawn at a legible minimum rather than true proportion — 512 MB of 476 GB is a third of a pixel. Each block is a flat token surface with 1px gold dividers and its size in mono underneath, so the bar is a diagram, not a chart pretending at precision.

01 · FIVE SLIDES, NO TRANSITION
Calamares' QML slideshow wants a fade. The CZD one holds a slide for 8 seconds and cuts — same rule as a signage board changing content, same rule as the Plymouth script. The whole slideshow is 40 seconds and loops until the install finishes.
02 · THE SLIDES TEACH, NOT SELL
Nobody reading an install progress bar needs to be told the distro is powerful. Each slide answers a question a first-time user will ask in the next ten minutes — where the tools are, what moved, who to tell when something breaks. Two sentences, then it stops.
03 · THE COUNTER IS THE REAL PROGRESS
Percentages lie during unpack. The package name and count sit above the rule at full ink so you can see it is moving even when the percentage sticks at 60 for four minutes — and the log path is on screen the whole time, not behind a details disclosure.
04 · DONE IS A STATE, NOT A DIALOG
No modal, no confetti, no checkmark. The headline swaps, the rule fills, the trace field takes its one surge pass, and the action bar grows the single filled-gold restart. Flip the install state tweak to see both frames — they are the same layout with different values.

01 · THE CHECKSUM IS THE HERO
A security conference publishing an unverifiable ISO is the joke that writes itself. The hash sits at full ink in the first column at 20px, the key fingerprint under it, and the verify commands are printed rather than linked — the page works for someone reading it on a phone at the registration desk.
02 · EIGHT PACKAGES, NAMED AND VERSIONED
The manifest is the whole argument of the project: this is a theme, delivered as packages, that can be removed. Every deliverable from batches 01–07 maps to a line here, and the token package sits at the top because the other seven generate from it.
03 · GREEN, ONCE, WHERE IT IS QUOTED
The #4FC26B success line appears because sha256sum printed it, not because CZD chose it — the same rule that lets the terminal palette exist. Outside quoted tool output, this sheet is gold on near-black like everything else.
04 · A SHEET, NOT A LANDING PAGE
This plate is the source for the website's download section and for the printed sleeve on the desk sticks — three columns of facts on one flat surface, no hero, no screenshot carousel, no "get started" button. The site already has this grid; it takes the content unchanged.
BATCH COMPLETE · The installer's first screen, the destructive screen and how it earns its weight without red, the slideshow as five held slides with the done-state on the same layout, and the release sheet that names the artifact, the eight packages and the way to verify them. With 08 the chain runs firmware → install → disk → desktop → download page.
SETTLED · The campus mirror stays TBC until it exists. Desk sticks carry the dateless default wallpaper, so a stick handed out on Saturday is not stale on Monday. No printed sleeve this year — a checksum sticker does the job. The image publishes as a GitHub release, live bootable and installable, with the site linking to it rather than hosting it.
