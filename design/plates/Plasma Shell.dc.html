01 · THE PANEL IS A RULE
56px, surface.raised #0B0A07, one 1px gold 26% hairline along the top and nothing else — no float, no rounding, no translucency, no shadow. Sections divide with 1px 13% verticals, the same hairline that stacks schedule rows. It reads as the bottom rule of the screen that happens to hold controls.
02 · WORDS, NOT ICONS
Task manager and tray are mono labels at 24px — the signage floor, because a panel is read at a glance from a lectern. Icons-only mode is off; there is no CZD icon set, and borrowing Breeze's would put a second visual language on the screen. Toggle tray labels in Tweaks for the narrow-screen variant.
03 · ACTIVE TASK
The focused window's entry takes the 0.05 gold tint plus a 1px gold bottom border and ink goes to #F4F0E6 — the nav selected state from the design system, unchanged. Hover adds the tint only. Minimised tasks drop to #6B6152 with no fill, the disabled treatment.
04 · DESKTOP ICONS
160px cells from x64 y64, straight down the quiet zone the wallpaper reserved. Icons themselves are dashed slots until batch 05 — the icon theme is its own deliverable and a stand-in glyph now would ship by accident. Labels are 24px mono in text.primary, which clears AA over the 1px deep traces underneath.

01 · THE WARM WELL
Kickoff is the only surface that uses surface.warm #181307 — the token's reassigned menu role from the map. Against the #0A0A0A desktop it reads as a plane change without a shadow or a blur, which is the whole reason that fourth surface exists. Category column drops to #050505 inset.
02 · APP ROWS ARE SCHEDULE ROWS
Archivo 600 at 30 over mono 400 at 24 — the one sanctioned pairing, and the same row the GRUB menu and the program guide use. No app icons, no grid of tiles: a launcher that lists what a tool does beats one that shows twelve logos you have to learn.
03 · DEFENSIVE FIRST
Default category is DEFENSIVE, not Favorites — this is Kali Purple, so the SOC tools are the point. Kali's own 01–13 offensive menu stays intact under ALL APPS; nothing upstream is removed, it is just not what opens first. CZD DOCS is disabled until there is something in it.
04 · NO SLIDE-IN
The popup cuts in at full opacity — Plasma's Dialog animation is set to 0ms and the launcher button takes the tint plus a 2px gold top cap while open. Search is focused on open, so the first keystroke filters. Anything Plasma does with 150ms easing by default is turned off in kdeglobals.

01 · FOCUS IS A VALUE SWAP
Active: 48px #0B0A07 titlebar, 1px gold 26% frame, title in #F4F0E6, controls gold. Inactive: #050505 titlebar, 13% frame, everything to #6B6152. No shadow separates them — the frame alpha and the titlebar value do the stacking, which is the system's only depth mechanism.
02 · THREE GLYPHS · EXTENSION
Flagged: window controls need pictograms and CZD has no icon set. Sanctioned route taken — 1px-stroke geometry in 24px boxes: a 14px rule, a 14px square, two crossed 18px rules. Nothing else in the build gets a glyph, and these three belong in the design system's iconography section on approval.
03 · WIDGETS FROM RULES
Every control is a 1px gold box with a square gold fill: toggle is 64×32 with a 24px knob, checkbox 28px with a 16px fill and no tick, slider a 2px track with a 16px square handle. Zero radius means a handle is a square and a switch is a rectangle — APPLY is the only filled gold on the screen.
04 · WHAT SHIPS
An Aurorae theme for the decoration (SVG frame parts, no blur), a Plasma style for the panel and popups, a colour scheme for Qt apps, and a Kvantum theme so GTK tools like Wireshark do not arrive in Adwaita grey. Four packages, one token file.
BATCH COMPLETE · Panel, launcher, and the window set — active, inactive, and the widget specimens on one 1920×1080 frame so a reviewer sees them against each other rather than in isolation. The desktop reuses wallpaper-default untouched, which is the test: if the shell needed the wallpaper to change, one of them was wrong.
OPEN · Icon theme is deliberately unbuilt — desktop icons, tray, and Dolphin's file list are dashed slots until batch 05 decides whether CZD inherits Breeze Dark monochrome recoloured to gold or ships nothing but type. Needs your call: whether the panel sits bottom (shown) or top — top reads more terminal, bottom is what every attendee expects — and whether DEFENSIVE opening ahead of Kali's 01–13 menu is acceptable to the Kali-literate crowd.
