THE CALL · Batch 04 left two routes open: recolour Breeze Dark monochrome to gold, or ship nothing but type. Neither. Words where a word fits, 1px geometry where it does not. File types are mono plates — PCAP reads faster than any drawing of a packet. The 33 drawn glyphs exist only for the places a label cannot go: a 56px panel tray, a 48px titlebar, a toolbar, a 64px desktop cell.
WHY NOT RECOLOUR · Breeze Dark is 4,000 icons in a different hand — soft corners, implied perspective, two-tone fills. Tinting them gold would put a second visual language on every screen and quietly undo the zero-radius rule. So the theme is small and honest: 33 cuts, and Inherits=breeze-dark in Index.theme so an unthemed app still resolves an icon instead of showing a broken-image box. If CZD did not draw it, it is Breeze's, and it looks like Breeze's.

Stroke lands on 1 device pixel at every size. 16 is hand-cut on its own 16-unit grid — not the 24 scaled down — and so is 22. Below 16 the theme does not ship; it falls through to Breeze.
THE 16 CUT · 14 UNIT LIVE AREA
Two units come off every edge instead of two-and-a-bit, the folder tab loses a unit of rise, and detail that cannot survive — the captures dot, the third slider handle, the fourth signal bar — is dropped rather than shrunk into mud. A 16 cut is allowed to say less than its 24.
BANNED
Curves · rounded corners · two-tone fill · outline-plus-shadow · perspective · mascots, shields, locks, circuit motifs — the logo already carries all of that.
01 · FOUR PRIMITIVES
Rule, 45° diagonal, open square, filled square. Every one of the 33 glyphs is assembled from those four and nothing else, which is why the set reads as one hand at a glance and why a new glyph takes ten minutes instead of an afternoon of curve matching.
02 · ONE COLOUR
Monochrome #E0A82E. No accent-on-accent, no status colour inside a glyph, no second tone to imply depth. Inactive drops to #6B6152 and hover goes to #FFE9A8 — the same three values links and rows already use.
03 · THE FILLED SQUARE IS RATIONED
A solid gold square inside a glyph means a live value — battery charge, signal strength, a recording in progress, a matched rule. If a glyph has no state to report, it has no fill. That keeps the loudest mark in the system meaning exactly one thing.
04 · HAND-SNAPPED, NOT SCALED
16, 22, 24, 32, 48, 64 — and 16 is drawn, not derived. A scaled 24 goes soft at 16, and a hairline rendering at 0.6px is the fastest way to make a terminal aesthetic look cheap. 32 / 48 / 64 come off the 24 grid by script; 16 and 22 are cut by hand. 198 files total, 66 of them hand work.

Every other mimetype, every Kali offensive tool, every KDE utility — Breeze Dark answers those. 33 glyphs is the whole theme and it stays that way unless a surface actually breaks.
01 · MIMETYPES ARE TYPE
A file list is the one place an icon is pure redundancy — the extension is right there in the name. So the mimetype "icon" is a 1px gold box holding a mono 700 label: PCAP, JSON, SH, KEY. Scannable at 22px, and a new type costs four characters, not a drawing.
02 · APPS EARN A GLYPH
Eight, and only the ones a SOC volunteer launches on day one. Each says what the tool does rather than what it is called: Arkime is capture columns, Suricata is a matched rule in a stack, Malcolm is a pipeline, TheHive is a case grid. Upstream brand marks are not replaced — Kali's own tools keep theirs.
03 · STATUS CARRIES A LEVEL
Signal, volume and battery report a value with filled squares against #4A320B empties — the barely-there gold from the ramp, which is what that step is for. Down and muted states go to #6B6152 plus a 45° strike; nothing in the tray ever turns red.
04 · THE THREE FROM BATCH 04
Minimize, maximize and close came out of the window decoration as ad-hoc geometry. They are now inventory items built to the same 24-unit grid, unchanged in appearance — the decoration stops carrying its own drawings and pulls from the theme like everything else.

01 · THE DASHED SLOTS ARE GONE
Every placeholder batch 04 left — desktop cells, tray, Dolphin's list, the toolbar — now resolves to a real cut. Nothing in the shell is pending except the Konsole scheme, which is batch 06. The wallpaper underneath is still wallpaper-default, untouched.
02 · TRAY: GLYPHS WIN HERE
Batch 04 spelled the tray out in words and it ate 340px of panel. Five 32px glyphs do it in 190px and still carry level. Words stay available — flip tray glyphs off in Tweaks to compare — but glyphs are the default now that a set exists.
03 · SEE THE LOSING VARIANT
Turn type plates off and the file list shows drawn document glyphs instead. Four identical shapes, no information, and the eye still goes to the extension in the filename. Keeping the comparison in the file is cheaper than relitigating it in a meeting.
04 · WHAT SHIPS
One directory: /usr/share/icons/czd-purple with Index.theme, six size folders, 198 SVGs and a mimetype map for the four plates. Installed by the respin package, set in kdeglobals, and inheriting breeze-dark so the other 4,000 icons keep working.
BATCH COMPLETE · Construction rules, the 33-glyph inventory with four mimetype plates, and the batch-04 surfaces rebuilt with every slot filled. The set is deliberately small — four primitives, one colour, six hand-snapped sizes — and it inherits breeze-dark rather than pretending to cover a whole desktop.
